# OnFire
Produit par Théo Benet-Chapard & Allan Thomas.

Voici notre application Swift. Sur cette app, vous pourrez voir de combien votre ville s'est réchauffée depuis 1981. Combien votre toit produirait-il d'énergie s'il comptait des panneaux solaires et leur rendement. Et enfin les différents feux de forêt par satellite.
